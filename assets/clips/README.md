# Video clips

Production Cat 2 animation clips live in **`cat2/`**.

| Folder | Contents |
|--------|----------|
| `cat2/` | Processed MP4 clips used by AI Meow 2 at runtime |

Re-encode or crop clips with:

```bash
node scripts/process-cat2-food-clips.js
```

Legacy WebM placeholders for Cat 1-style dev are still under `assets/cat2/`.
